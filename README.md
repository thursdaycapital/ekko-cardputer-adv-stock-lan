# Ekko Studio · M5Stack Cardputer-Adv

**v10.0.0-alpha.5 开发预览，仅局域网；本轮完整实体恢复验收仍在进行。**

直接连接官方 Ekko Studio，无需修改电脑端核心或另起桥接服务。保留16 Agent、中文输入、12px 字体、头像、启动视频、按键声和原设备中的原厂工具。Ekko聊天录音使用RAM，不需要SD卡。

## 日常只需三步

1. 原厂菜单连接 Wi-Fi，进入「EkkoStudio」。首次在设备 `/device` 原生管理页选择同网电脑、登录一次、选择 Profile；已有绑定继续复用。
2. 方向键选 Agent，Tab 选「Studio模型／原生CLI」，按一次 OK 进入。原生模式使用电脑上该CLI自己的配置和登录。
3. 打字后按 OK 发送；Ctrl＋空格切中英文。长按 G0 或 Fn＋空格说话，松开发送，采集就绪后最多5秒。短按 G0／Esc 返回，Fn＋上下翻记录。

临时断线保留绑定和草稿。发送结果不确定时先 Fn＋R 核对，不自动重复发送；按提示确认后再继续。无远程中继支持。

## 本版修复

- 新会话历史接口返回500时，不再无休止等待：只有明确属于设备的本地会话，经官方本地接口严格确认不存在，才按空历史处理。权限错误、其他服务器错误及旧远端会话不被当作空记录。
- Studio模型选择跟随官方新对话的兼容规则，显示一次实际提供方／模型，不静默换Agent。
- 明确选择原生CLI默认模型时，模型目录的探测失败不再拦住实际能运行的Cursor。真实鉴权拒绝、未安装和超时仍正确报告。
- 保留未确认发送提示；后台数据序列化错误显示为可读中文原因。

## 实际测试结果

2026-11-16，在本机独立运行官方0.8.24代码，按普通用户操作逐个测试16 Agent：14个收到回复；Grok、Qoder保留失败，详见[逐项结果](evidence/v10-alpha5-20261116/desktop-ui-matrix.json)。隔离实例的配置和登录组件与日常实例存在说明中的差异，不能把结果当作所有电脑都可用。

Grok的CLI不能解析当前提供方的 `response.metadata` 事件，官方网页也失败；Qoder原生CLI提示模型不可用。没有修改官方核心、换Agent或更换模型来掩盖失败。另一次补充矩阵中Claude超时，虽然独立普通网页测试成功，超时事实仍保留。

34组主机回归、392个中文字符覆盖和ESP32-S3构建通过。这些不代表本版已完成M5打字、实际声音、断网、断电及令牌过期恢复。alpha3曾取得G0返回、语音及5秒墙钟停止的实机证据，历史结论不冒充alpha5验收。见[已知问题](已知问题.zh-CN.md)。

## 安装与范围

此包是已具有本项目双固件布局设备的应用更新，**不是新机通用首刷包**。本版应用文件为 `firmware/ekko-cardputer-next-0x10000.bin`，只写 `0x10000`。不包含或改写原厂、分区表、NVS、个人设置或文件系统；刷前保留私有完整备份，并读回核对。[安装教程](安装教程.zh-CN.md) · [回退说明](回退说明.zh-CN.md)。

应用3,321,056B，现有应用分区余21,280B；静态RAM115,916B，设备没有PSRAM。这不等于运行时可用内存；本版动态内存和录音峰值仍需实体测量。录音为16kHz单声道、RAM IMA4有界暂存，TTS流式播放。

兼容协议基线为官方0.7.36，本轮桌面测试版本为0.8.24。发布包不包含Wi-Fi密码、账户密码、JWT、API Key、个人NVS、完整Flash或原始设备日志。官方模型接口可能返回密钥，固件过滤且不持久化这些字段，不能宣称密钥从不经过设备。
