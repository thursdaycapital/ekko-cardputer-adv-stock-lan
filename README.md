# Ekko Studio · M5Stack Cardputer-Adv

**v10.0.0-alpha.6 开发候选：源码已同步 GitHub，Release 仍为草稿；仅局域网，完整实体验收尚未完成。**

直接连接官方 Ekko Studio，无需修改电脑端核心或另起桥接服务。保留 16 Agent、中文输入、12px 字体、官方头像、启动视频、按键声及设备已有原厂工具。Ekko 聊天录音使用有界 RAM，不需要 SD 卡。

## 日常使用

1. 原厂菜单连接 Wi-Fi，进入「EkkoStudio」。首次在设备 `/device` 原生管理页选择同网电脑、登录一次并选择 Profile，已有绑定继续复用。
2. 方向键浏览 Agent，Tab 选择 Studio 模型／原生 CLI，按一次 OK 激活并进入聊天。原生模式使用电脑上该 CLI 的登录和配置。
3. 打字后按 OK 发送，Ctrl＋空格切换中英文。长按 G0 或 Fn＋空格说话，松开发送；采集就绪后最多五秒。短按 G0／Esc 返回，Fn＋上下翻记录。

临时断线保留绑定和草稿。发送结果不确定时先按 Fn＋R 核对，按提示确认后再继续，固件不会自动重复发送。本候选不支持远程中继。

## alpha6 修复

自动重新登录读取官方电脑身份时，PEM 公钥的标准 LF／CRLF 换行不再被误判为非法控制字符。只放行公钥中的这两类换行；电脑身份、令牌、其他字段、长度和完整绑定匹配仍严格校验。没有迁移密码、放宽 HTTP 鉴权或跳过身份校验。

保留 alpha5 的严格本地 404 空历史恢复、官方兼容默认模型选择、Explicit Native 默认模型的目录提示放行、未知发送核对及后台格式错误中文提示。原生目录提示并不保证 CLI 实际运行成功。

## 安装边界

此包仅供已经具有本项目 ESP32-S3／8MiB 双固件布局的 M5Stack Cardputer-Adv 更新应用，**不是陌生设备或新机首刷包**。唯一应用为 `firmware/ekko-cardputer-next-0x10000.bin`，只写 `0x10000`，长度 3,321,072B、SHA-256 以清单为准。现有 `0x330000` 应用槽余 21,264B；静态 RAM 115,916B，没有 PSRAM。静态 RAM 不等于运行时空闲内存。

不包含原厂镜像、分区表、NVS、个人设置、文件系统或整片 Flash。刷前保存私有完整备份并核对布局，刷后逐区域读回。[安装教程](安装教程.zh-CN.md) · [回退说明](回退说明.zh-CN.md) · [重新链接](RELINK.md)。

兼容协议基线为官方 0.7.36，本轮隔离恢复实例为 0.8.24。官方模型接口可能返回 API Key，固件流式过滤且不持久化；不能宣称密钥从不经过设备。公开候选不包含 Wi-Fi 密码、账号密码、JWT、API Key、NVS、完整备份或原始设备日志。
