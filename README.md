# Ekko Studio · Cardputer ADV 局域网固件

**官方 Studio 免电脑补丁 · 开发预览版 `v9.0.0-dev.10-lan`**

让 M5Stack Cardputer ADV 直接连接官方原版 Ekko Studio：16 Agent 选择目录、中文打字、聊天历史和 Fn＋空格语音。设备端适配标准聊天与语音接口；电脑不需要本项目补丁或额外桥接服务。

> 当前仅支持同一局域网。远程中继尚未接入；电脑开启远程开关不会让本版自动支持跨网。此版本不是所有验收均完成的稳定版，也不是未知新机的通用首刷包。

## 能做什么

- 方向键选择 16 个 Agent，OK 进入聊天，Esc 返回；实际运行取决于电脑安装、授权及模型配置。
- 中文／英文打字，Ctrl＋空格切换，拼音空格选词、OK 发送。
- 按 Agent、Profile 和会话隔离历史，分页读取；Tab 进入浏览。
- Fn＋空格按住说话、松开发送：录音压缩暂存 RAM，单次最多五秒，无需 SD 卡；经官方 STT、当前 Agent 和 TTS 返回。
- 保留中文12px字体、官方来源头像、四秒启动视频和按键声。原厂独立工具继续保留在原设备应用中。
- 首次在 M5 的 `/device` 网页选择同网电脑、登录本机 Studio 账号并选 Profile；之后使用保存的绑定恢复。

## 已验证与限制

| 范围 | 结果 |
| --- | --- |
| 官方 Studio 0.7.36 | 真实 M5 文字、语音识别、回答和实际声音获用户确认，无电脑补丁。 |
| 官方 Studio 0.7.37 | 更新后自动重连及文字回复获用户和设备记录确认；本轮没有重新做新版语音验收。 |
| 无 SD 语音 | 短录采集无溢出、播放无写超时；用户确认五秒自动停止。完整五秒字节及中途断网压力记录尚未齐全。 |
| 16 Agent | 目录完整；隔离官方后端13路真实回答，Hermes／Pi／Cursor限制单列，不能写成全部已在M5通过。 |
| 恢复 | 已观察保存绑定、新应用启动和后台重启后恢复；真实时间过期及完整异常矩阵仍未全部实测。 |
| 存储 | ESP32-S3，8MiB Flash，无PSRAM；应用槽剩58,336B，录音上限五秒。 |

本仓库不包含 Studio 账号、Wi-Fi 密码、API Key、认证 Token、聊天录音／截图、运行数据库或私有整机备份。官方模型接口的授权响应可能包含 API Key，设备过滤这些字段，不宣称密钥从不经过设备。
